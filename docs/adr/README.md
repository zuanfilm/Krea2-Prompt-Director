# Architecture Decision Records

This directory contains the Architecture Decision Records (ADRs) for VizClick.

Each ADR documents an important architectural decision, the reasoning behind it, the alternatives considered, and its long-term consequences.

The goal is to preserve not only *what* the architecture is, but *why* it became that way.

Examples include:

- Creative Representation Layer
- Production Brief as Intermediate Representation
- Activation Network
- Visual Markup Language (VML)
- Renderer Independence
- Human and AI as Creative Participants

Every major architectural change should be accompanied by a new ADR.

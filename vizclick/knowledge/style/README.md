# Style

Style describes the artistic language through which a creative work is
expressed.

Style influences aesthetic decisions without prescribing technical
implementation.

Style concepts are independent of any renderer, software, or prompt
syntax.

## Purpose

The Style domain defines reusable visual languages that establish the
overall artistic identity of a creative work.

## Examples

- Editorial Fashion
- Film Noir
- Minimalism
- Documentary
- Fine Art
- Luxury

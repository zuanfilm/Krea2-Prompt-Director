# Color Palette

Color Palette describes the overall chromatic language of a Creative
Representation.

Color concepts influence emotion, atmosphere, harmony, and visual
identity independently of renderer-specific color controls.

## Purpose

The Color Palette domain defines reusable concepts that establish the
color relationships of a creative work.

## Examples

- Neutral Palette
- Warm Palette
- Cool Palette
- Earth Tones
- Jewel Tones

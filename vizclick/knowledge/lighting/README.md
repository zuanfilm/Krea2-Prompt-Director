# Lighting

Lighting describes how illumination shapes the visual perception,
mood, depth, and dimensionality of a Creative Representation.

Lighting concepts focus on creative intent rather than technical lighting
setups.

They remain renderer-independent and describe visual outcomes rather
than implementation details.

## Purpose

The Lighting domain defines reusable concepts that control how light
contributes to storytelling and visual communication.

## Examples

- Soft Diffused Lighting
- Rembrandt Lighting
- Butterfly Lighting
- Rim Lighting
- Golden Hour
- Window Light

# Composition

Composition describes how visual elements are organized within the
frame.

Composition guides attention, balance, rhythm, and visual storytelling.

These concepts remain independent of renderer-specific composition
controls.

## Purpose

The Composition domain defines reusable concepts that organize visual
information to strengthen communication and storytelling.

## Examples

- Rule of Thirds
- Symmetry
- Leading Lines
- Negative Space
- Layered Depth
- Centered Composition
